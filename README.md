## 🛠️ التقنيات

- **Next.js 16** (App Router) + TypeScript 5
- **Tailwind CSS 4** + shadcn/ui
- **Cloudflare D1** (حفظ طلبات التواصل في قاعدة بيانات Worker)
- **Resend** (إشعارات البريد الإلكتروني عبر HTTP)
- **Framer Motion** (حركات الظهور عند التمرير)
- **next-themes** (الوضع الفاتح/الداكن)
- خط **Cairo** (عربي/لاتيني، مستضاف ذاتيًا عبر next/font)

## 🚀 التشغيل

1. **كسب العمل (المرتبات)** — تأمينات 11%/18.75% بحدود سنوية، إعفاء شخصي 20,000، شرائح 2023-2026
2. **ضريبة الدخل** — أفراد (شرائح تدريجية) / شركات (22.5% موحد)
3. **الضريبة الإضافية** — 1.5% شهريًا (حد أقصى 36 شهرًا قبل الإخطار + بلا حد بعده)
4. **غرامة التأخير** — فوائد سنوية متغيرة 2016-2026، فردي (1 أبريل) / شركة (1 مايو)

جميع المحركات مُختبرة بنسبة 100% مقابل أمثلة مرجعية (اتساق كامل مع منهجية المصلحة) — لا مجال للخطأ.

## 🏛️ قسم مستجدات مصلحة الضرائب المصرية (SEO)

قسم مستقل كامل (`#eta-news`) بعد الحاسبات مباشرة يتضمن:

- **عنوان ونصوص SEO ثابتة** قابلة للفهرسة بالعربية والإنجليزية
- **أحدث الأخبار** — لحظيًا من `eta.gov.eg/ar|en/news` عبر `/api/eta-news` (كاش 30 دقيقة + زر تحديث)
- **القوانين والخدمات الرسمية** — قوانين القيمة المضافة، ضريبة الدخل، الكتب الدورية، الفاتورة الإلكترونية، البوابة
- **إعلان العرض** — بانر ذهبي لعرض «استشارة ضريبية أولى مجانية»

**أمان قسم الأخبار:** هدف المصدر ثابت في الكود (استحالة SSRF) + مهلة 8 ثوانٍ + سقف 2MB + تعقيم كامل + تحديد معدل + كاش + تراجع آمن.

## 📧 إشعار البريد عند وصول طلب جديد (مراجعة فورية)

كل طلب من نموذج التواصل يُرسَل إلى `Ak.officeacc@gmail.com` عبر Resend بقالب HTML أنيق (الاسم/الهاتف +20/البريد/الخدمة/الرسالة) بلغة المرسل، إضافة إلى حفظه في Cloudflare D1.

**الإعداد المحلي:**
1. أنشئ مفتاح إرسال محدود الصلاحيات من [Resend API Keys](https://resend.com/api-keys)
2. أضف القيم في `.dev.vars`:
```
RESEND_API_KEY=re_xxxxxxxxx
CONTACT_NOTIFY_EMAIL=Ak.officeacc@gmail.com
CONTACT_FROM_EMAIL=Office Website <onboarding@resend.dev>
```

> في الإنتاج، عيّن القيم نفسها كـ Secrets في Cloudflare Workers، واستخدم عنوان `from` من نطاق موثّق في Resend.

## 🔒 الحماية (النسخة المدقَّقة أمنيًا)

**API نموذج التواصل:**
- تحديد المعدل: 5 طلبات/دقيقة لكل IP → 429 + Retry-After (نافذة منزلقة)
- مصيدة بوتات (honeypot): حقل `website` مخفي — البوت يحصل على رد نجاح وهمي
- تحقق Zod من كل الحقول + تجريد المفاتيح غير المعروفة
- حد حجم الطلب: رفض مبكر عبر Content-Length + قراءة متدفقة بحد 40KB
- ردود عامة بلا تسريب + `Cache-Control: no-store`

**محدد المعدل:** سقف 10,000 مفتاح + تعقيم المفاتيح

**رؤوس الأمان:** CSP صارم في الإنتاج، HSTS، nosniff، X-Frame-Options، Referrer-Policy، Permissions-Policy

**الخصوصية:** لا تسجيل PII في السجلات، قاعدة البيانات للكتابة فقط، robots.txt يمنع فهرسة الـ API

**الواجهة:** روابط خارجية `rel="noopener noreferrer"`، لا `dangerouslySetInnerHTML`، قيم اللغة محصورة، حقول بلا تراكب

**ملحوظة نشر:** استخدم `bun run deploy` بعد إنشاء قاعدة D1، ووضع `RESEND_API_KEY` و`CONTACT_NOTIFY_EMAIL` و`CONTACT_FROM_EMAIL` كـ Secrets في Cloudflare Workers.
